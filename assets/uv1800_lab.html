Alur praktikum virtual

1. Persiapan. Kenali bagian instrumen dan workstation.
2. Buka kompartemen. Klik “Buka kompartemen”.
3. Masukkan kuvet. Letakkan kuvet demonstrasi ke dudukan.
4. Tutup kompartemen. Tutup sebelum menjalankan pengukuran.
5. Atur parameter. Buka tab Software PC, pilih mode dan panjang gelombang.
6. Ukur. Klik RUN MEASUREMENT untuk menampilkan data simulasi.

Catatan pembelajaran

Model ini dibuat untuk eksplorasi visual dan latihan urutan kerja. Nilai hasil tidak berasal dari sumber cahaya, detektor, atau sampel nyata. Ikuti SOP dan manual instrumen untuk praktikum sesungguhnya.
